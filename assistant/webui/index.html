Library

Everything you have made. Each card is a folder in projects/ — what it is, how many dimensions it has, the pieces it is made of and the files it has exported. Pictures are kept from the last time it was rendered.

Models

Every 3D file on this machine Forge can see — the meshes the picture-to-3D service generated, and anything in projects/<name>/models/. Newest first. Click a card to open that model in Blender — it lands in your scene if Blender is running, and Blender starts with it if not. Or file one into a project so it lives beside its part.

In progress

What Blender is holding right now — a generated mesh, a sculpt, the pieces a segment produced. These have no folder yet, which is fine; they are still your work.

Flows
